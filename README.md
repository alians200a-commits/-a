# قِرَاءَتِي — الصف الأول الابتدائي

تطبيق قراءة تفاعلي عربي مبني على ملفات مشروع القراءة الأصلية، مع واجهة رحلة جديدة، استئناف آخر نشاط، وخريطة الدروس ومتابعة للأهل.

## التشغيل

```sh
python3 -m http.server 8080
```

افتح http://localhost:8080/app/ . يعمل من مسار فرعي بما يناسب GitHub Pages. يمكن تثبيته من المتصفح، ويخزّن محتواه للعمل دون إنترنت بعد اكتمال التنزيل الأول.

## التحقق

```sh
node tests/run.js
```

هذا اختبار بناء الشاشات بمحاكاة DOM، وليس بديلًا عن تجربة الألعاب الفعلية في المتصفح.

## المحتوى والقرارات

- 32 درسًا، و17 نشاطًا في مسار كل درس؛ جميع الدروس مفتوحة.
- الصور الأصلية والخطان المحليان محفوظة في app/.
- بيانات الدروس في app/data.js بقيت دون تغيير؛ مطابقتها الكاملة لصفحات الكتب تحتاج تدقيقًا تعليميًا منفصلًا.
- النطق مؤجل بقرار سابق؛ لا صوت متصفح. توجد نغمات قصيرة للألعاب فقط.
- التقدم محفوظ محليًا على الجهاز، ولا يوجد حساب أو مزامنة سحابية.
- علامة الإكمال تصف إنهاء المسار، وليست شهادة إتقان.
- لم تُضمّن ملفات الكتب PDF والتسجيلات المؤجلة في نسخة التطبيق المنشورة.

## الملفات

- app/app.js: التنقل والأنشطة وواجهات البداية والمتابعة.
- app/games.js و app/games2.js: الألعاب.
- app/style.css: التصميم المتجاوب.
- app/sw.js: التخزين للعمل دون إنترنت.
- app/manifest.json: إعدادات تثبيت تطبيق الويب.

تطبيق مستقل غير معتمد رسميًا من وزارة التربية العراقية.
