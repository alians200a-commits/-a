# قراءتي — درس «ا / ى»

مراجعة تصميم قيد التقييم بعد رفض التنفيذ السابق: شخصيات وصور ثلاثية الأبعاد، واجهة عربية، وخلفية دافئة بأزرار تركوازية. هذه النسخة تحل محل وصف المشروع السابق المرفوض؛ لم يُنقل محتواه أو خططه ذات 32 درسًا؛ أُعيد استخدام ملف خط Noto Naskh الذي طلبه المستخدم.

## التشغيل

لا تحتاج مفاتيح API أو حزم خارجية. التشغيل المتوافق مع Google AI Studio: `npm run dev` على المنفذ 3000. البناء: `npm run build` ينتج مجلد dist. الفحص: `npm test`. ويمكن تشغيل النسخة الثابتة من جذر المستودع:

```sh
python3 -m http.server 8080
```

افتح http://localhost:8080 . ويمكن فتح index.html مباشرة للتجربة، مع اختلاف دعم التخزين المحلي بحسب المتصفح. جميع الصور محلية والمسارات نسبية لتناسب الاستضافة داخل مجلد فرعي. الرفع إلى GitHub وحده لا ينشر موقعًا عامًا؛ لم تُفعّل GitHub Pages أو خدمة استضافة في هذه الخطوة.

## المنفّذ

- استكشاف خمس كلمات بصورها: دار، غزال، حلوى، مرمى، عصا.
- اختيار ا وى من مجموعة حروف، مع تغذية راجعة وعدم احتساب الإجابة الخاطئة.
- تتبع الحرفين بالإصبع أو الفأرة؛ تحقق مرتب من المسار يمنع إكمال الحرف بنقرة واحدة أو القفز لنهايته.
- إكمال نار، مرمى، دار، حلوى، عصا باختيار الحرف.
- حفظ تقدم محلي بنسخة بيانات مستقلة، واستئناف النشاط ومراجعة الدرس ومسح تقدمه.
- تصميم متجاوب للهاتف والتابلت، وأزرار معنونة ورسائل حالة لقارئ الشاشة.

## المصادر التعليمية

ملف `قراءة_الصف_الاول_الابتدائي_المنهج_الجديد_ (1).pdf` المرفوع: الصفحتان المطبوعتان 11 و12 (صفحتا PDF 12 و13). شكل الأنشطة مقتبس تفاعليًا؛ ليس نسخة حرفية من ترتيب الصفحة. كتاب النشاط المرفوع مصدر للتوسعة المقبلة، ولم تُدرج تمارينه الإضافية بعد. لا تُضاف أي كلمات من المنهج القديم.

## حدود هذه النسخة

- **المشهد ثابت، وليس فيديو**. الفيديو مؤجل بناءً على توجيه صاحب المشروع؛ الصورة الثابتة معتمدة لهذه المرحلة. لا توجد حركة صورة توهم بأنها حركة شخصيات.
- **التسجيلات الصوتية غير مضافة**. لا زر تشغيل وهمي ولا نطق آلي غير مراجع. مرحلة الاستماع ستضاف مع الملفات الصوتية الصحيحة.
- التتبع مسار مبسط للتدريب الحركي؛ يحتاج مراجعة تربوية واتجاه رسم الحرف قبل إطلاق نهائي.
- التشكيل والتسجيلات يحتاجان تدقيقًا تعليميًا؛ الكلمات الحالية بلا تشكيل.
- ليست كل المناهج منفذة؛ الدرس العامل الوحيد حاليًا ا/ى. الترتيب التالي المخطط: و ثم ي ثم ب.
- لا حسابات أو مزامنة أو تثبيت PWA أو تخزين Service Worker. الحفظ المحلي قد يتعذر في بعض إعدادات المتصفح.
- الإكمال يعني إنهاء الأنشطة، لا قياس الإتقان.

## ملفات المشروع

`index.html` الواجهة، `style.css` أساس التصميم و`redesign.css` المراجعة الحالية، `lesson.js` الكلمات ومراجعها، `app.js` الأنشطة والحفظ، `trace.js` تحقق مسار التتبع، `assets/` الصور، `tests/logic.test.cjs` تحقق المحتوى والتتبع.

تشغيل تحقق المنطق:

```sh
node --test tests/logic.test.cjs
```

هذه الاختبارات لا تعوض تجربة لمس فعلية على هاتف. انظر VALIDATION.md لنتائج الفحص وحدوده.

## إعادة الاستخدام والحقوق

الصور الجديدة مولدة للمشروع وفق المرجع الذي قدمه المستخدم. أُدمج canvas-confetti 1.9.3 فعليًا لمؤثر النجاح، مع احترام تقليل الحركة. المصدر: https://github.com/catdad/canvas-confetti، الرخصة ISC في CONFETTI-LICENSE.txt. خط Cairo من google/fonts وخط Noto Naskh من أصول المشروع السابق، ورخصتا OFL مرفقتان في assets/fonts. الخطان مضمنان محليًا بصيغة WOFF. أُدمج كود تتبع مكيّف من Kitkit School فعليًا في vendor/kitkit-trace-locator.js ويستدعيه trace.js؛ المصدر والإصدار والتعديلات موثقة في THIRD_PARTY.md ورخصة Apache-2.0 مرفقة. لم تُدمج أصوات أو شخصيات من هذه المشاريع. تبقى Antura وFeed the Monster وKatkooti وSima وonebillion مصادر مرشحة لدراسة أفكار التتبع والتدرج والصوت، ولا يعني ذلك أن أصولها مرخصة تلقائيًا لإعادة الاستخدام. يلزم فحص ترخيص أي ملف يُختار مستقبلًا وحفظ نسبه.

## مراجعة التصميم الحالية

مشهد حديقة وبطاقات كلمات مصورة، خط نسخ للكلمات وكايرو للواجهة، استجابة مرئية للأزرار ومؤثر نجاح. العناوين تستخدم Lalezar المضمّن محليًا كبديل مؤقت متاح؛ ليس Tufuli أو بلابيلو أو سمكة. الكلمات تستخدم Noto Naskh والتعليمات Cairo. ليست هذه مراجعة معتمدة من المستخدم، ولم تُفحص بصريًا في متصفح.
