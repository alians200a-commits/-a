# حديقة الحروف — 0.6

تطبيق ويب عربي RTL لدرس ا/ى من منهج الصف الأول العراقي الجديد المرفوع. واجهة عالم أطفال، خريطة من أربع محطات، اكتشاف خمس كلمات، اختيار الحروف، تتبع إرشادي، إكمال الكلمات وحديقة إنجازات محفوظة محليًا.

## التشغيل

```sh
npm run dev
```

يفتح خادم Node على المنفذ 3000؛ لا يحتاج اشتراكًا أو مفتاح API أو تثبيت حزم. `npm test` للفحوص، و`npm run build` لبناء dist.

## الاستيراد

استورد الفرع main من `alians200a-commits/-a` كمشروع جديد داخل Google AI Studio. النسخة المستوردة سابقًا لا تتحدث تلقائيًا. لا تدفع نسخة قديمة من Studio فوق تحديثات المستودع.

## التصميم والتنفيذ

- عائلتا خط محليتان: Lalezar للعناوين، Cairo لجميع النصوص والحروف الأخرى. Lalezar بديل مؤقت وليس Tufuli.
- لوحة كتاب تفاعلية ومشهد مستقل، أزرار فعلية ومؤثرات جمع الحروف وظهور الزهرات.
- Anime.js لتنسيق الانتقالات؛ كود تتبع مكيّف من Kitkit School؛ تفاعلات مكيّفة من مستودع المستخدم. التفاصيل والتراخيص في THIRD_PARTY.md.
- الرسومات ثابتة. لا فيديو أو تسجيلات صوتية حاليًا.
- الرئيسية والحديقة لا تمنح إنجازات لم تُنجز، والبيانات تبقى على الجهاز.

## حدود هذه النسخة

المحتوى هو درس ا/ى فقط؛ بقية المنهج غير منفذة. نجحت الفحوص الوظيفية، ولم تُجر معاينة بصرية أو تجربة لمس لهذه النسخة. راجع VALIDATION.md. يحتاج مسار كتابة ى مراجعة تربوية. الأصول المصورة ليست بديلًا عن مراجعة النص والمحتوى.

## الجديد في 0.6

- ساحة لعب: مطابقة بخمس جولات، ذاكرة صورة وكلمة، صيد ا/ى، وتلوين كلمات كتاب النشاط (ملك، مال، هدى، هادي).

- مرجع القراءة: الصفحتان ١١ و١٢ المطبوعتان. مرجع التلوين: كتاب النشاط المرفوع صفحة ٥، نشاط ٢.

## إصدار 0.7 — أنشطة الواو

أضيف اختيار درس الألف أو الواو، وحفظ مستقل للتقدم والجوائز. كلمات الواو: خروف، حوت، صوص، ليمون؛ صف الحروف وتمرين الإكمال والتتبع من القراءة صفحة 14، والتلوين (زيتون، دبوس، دب، صابون) من كتاب النشاط صفحة 6. هذه مجموعة أنشطة وليست تغطية كاملة لصفحتي درس الواو. الألعاب الأربعة تتكيف مع الدرس.

مشهد الخروف مصمم بالشخصيتين. صور الحوت والصوص والليمون مؤقتة من الكتاب المرفوع؛ توقف توليد مشاهدها بسبب حد الاستخدام. الخطوط بقيت عائلتين فقط. لا اعتماد بصري نهائي ولا اختبار لمس أو متصفح فعلي لهذه النسخة.
