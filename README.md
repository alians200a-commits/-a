# حديقة الحروف — 0.5

تطبيق ويب عربي RTL لدرس ا/ى من منهج الصف الأول العراقي الجديد المرفوع. واجهة عالم أطفال، خريطة من أربع محطات، اكتشاف خمس كلمات، اختيار الحروف، تتبع إرشادي، إكمال الكلمات وحديقة إنجازات محفوظة محليًا.

## التشغيل

```sh
npm run dev
```

يفتح خادم Node على المنفذ 3000؛ لا يحتاج اشتراكًا أو مفتاح API أو تثبيت حزم. `npm test` للفحوص، و`npm run build` لبناء dist.

## الاستيراد

استورد الفرع main من `alians200a-commits/-a` كمشروع جديد داخل Google AI Studio. النسخة المستوردة سابقًا لا تتحدث تلقائيًا. لا تدفع نسخة قديمة من Studio فوق تحديثات المستودع.

## التصميم والتنفيذ

- عائلتا خط محليتان: Lalezar للعناوين، Cairo لجميع النصوص والحروف الأخرى. Lalezar بديل مؤقت وليس Tufuli.
- لوحة كتاب تفاعلية ومشهد مستقل، أزرار فعلية ومؤثرات جمع الحروف وظهور الزهرات.
- Anime.js لتنسيق الانتقالات؛ كود تتبع مكيّف من Kitkit School؛ تفاعلات مكيّفة من مستودع المستخدم. التفاصيل والتراخيص في THIRD_PARTY.md.
- الرسومات ثابتة. لا فيديو أو تسجيلات صوتية حاليًا.
- الرئيسية والحديقة لا تمنح إنجازات لم تُنجز، والبيانات تبقى على الجهاز.
