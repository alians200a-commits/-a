# قراءتي — حديقة الحروف 0.4

درس «ا / ى» من المنهج العراقي الجديد. هذه مراجعة للتصميم بعد ملاحظات المستخدم؛ ليست اعتمادًا نهائيًا للجودة البصرية.

## التشغيل

- `npm run dev` أو `npm start`: خادم Node على المنفذ 3000، بلا حزم خارجية أو مفاتيح API.
- `npm run build`: نسخة ثابتة في dist، مع تنظيف ناتج البناء السابق.
- `npm test`: فحوص الوظائف والمحتوى وموارد الخادم.

## التصميم الحالي

- خطان فقط: Lalezar للعناوين، وCairo للكلمات والحروف والأزرار والتعليمات. Noto Naskh محذوف من التوزيع.
- ملف style.css موحّد بدل تكديس قواعد style.css وredesign.css.
- تخطيط بطول مساحة العرض، مع شريط أنشطة وزر متابعة خارج منطقة تمرير النشاط. يظل التمرير متاحًا للمحتوى على الشاشات القصيرة.
- بطاقات بلون أساس موحّد؛ اللون الأخضر يميّز الإجابة الصحيحة. العداد باتجاه واضح.
- motion.js: دخول متتابع، استجابة ضغط، ميل طفيف للماوس، انتقال الحرف الصحيح إلى خانته، وإبراز الكلمة. حركة الصور لا تُقدّم كأنها تحريك شخصيات.
- تكيف مؤثرات مستودع المستخدم mudarrisi-reading-app موثّق في THIRD_PARTY.md؛ لا نقل لمحتوى منهج سابق.
- إيقاف الحركات عند تفضيل تقليل الحركة؛ لا تفكيك للحروف العربية المتصلة في حركات ظهور النص.

## الأنشطة

استكشاف دار، غزال، حلوى، مرمى، عصا؛ اختيار ا وى؛ تتبع الحرفين مع عرض إرشادي؛ إكمال نار، مرمى، دار، حلوى، عصا. حفظ محلي للتقدم دون حساب. كود التتبع مكيّف من Kitkit School ومرفق برخصته.

المصدر: كتاب القراءة الجديد المرفوع، الصفحتان المطبوعتان 11 و12 (PDF 12 و13). لم تُوسّع هذه المراجعة المنهج. فيديو الشخصيات مؤجل حسب طلب المستخدم، والصوت التعليمي غير مضاف. مسار الكتابة تدريب مساعد يحتاج مراجعة تربوية؛ الإكمال لا يثبت إتقان الخط.

## حدود التحقق

نجحت اختبارات الوظائف وبناء الملفات. لم تُجر معاينة بصرية فعلية أو تجربة لمس لهذه المراجعة؛ لا تُعد الاختبارات إثباتًا للتناسق أو لحركة الواجهة. انظر VALIDATION.md.
